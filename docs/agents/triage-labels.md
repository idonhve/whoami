# 分诊标签

各技能使用五个标准分诊角色来沟通。本文件把这些角色映射到本仓库 issue 跟踪系统中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签     | 含义                              |
| -------------------------- | -------------------- | --------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue           |
| `needs-info`               | `needs-info`         | 等待提交者补充更多信息             |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整，可交给 AFK 智能体执行  |
| `ready-for-human`          | `ready-for-human`    | 需要人工来实现                     |
| `wontfix`                  | `wontfix`            | 不会处理                           |

当技能提到某个角色（例如"打上 AFK 就绪的分诊标签"）时，使用上表中对应的标签字符串。

如果你实际使用的是别的词汇，直接修改右列即可。
