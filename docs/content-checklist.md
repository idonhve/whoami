# 内容准备清单（站主素材收集用）

> 用途：在一个**独立会话窗口**中，由 Agent 按本清单逐项向站主收集素材，整理为 `docs/content/` 下的素材底稿（Markdown + 图片/PDF 文件），供数据库初始化与后台录入使用。
> 填写方式：Agent 逐区提问，站主口头/粘贴/传文件均可，Agent 负责整理归档。

## 0. 基本信息（F1 / F3 / F7 依赖）

* [ ] 姓名（用于首页 Hero 与简历文件名，如 `张三`）

* [ ] 一句话定位（≤20 字，如"全栈工程师 / 终端美学爱好者"）

* [ ] GitHub 用户名

* [ ] GitHub 个人访问令牌 PAT：classic 只勾 `public_repo`，或 fine-grained 只读公开仓库；过期时间建议 90 天（**密钥只写入本地** **`.env`，不进 git**）

* [ ] 联系邮箱（可选，用于控制台彩蛋的招聘联系方式）

## 1. 简历 PDF（F7）

* [ ] 最新简历 PDF 1 份，≤20MB，命名建议 `姓名_简历_2026-08.pdf`

## 2. 技术栈（F2）——建议 10\~20 项

每项一行：`名称 | 分类（前端/后端/数据库/工具）| 熟练度（精通/熟练/了解）| 权重 1-10`

示例：`Vue 3 | 前端 | 熟练 | 9`

* [ ] 技术项清单（按上述格式）

## 3. 作品（F4）——仓库数据由 GitHub 同步，只需人工补运营信息

* [ ] 每个想展示的仓库：中文描述一句（≤30 字）

* [ ] 置顶候选 ≤3 个（仓库名）

* [ ] 需隐藏的仓库名（同步后不在前台展示）

## 4. 工作经历（F9）——每段经历一套

* [ ] `公司 | 职位 | 起止时间`（如 `XX科技 | 高级后端 | 2023.03 - 至今`）

* [ ] 核心战果 1\~3 个：`数字+单位 + 一句话语境`（如 `300%｜核心接口查询性能提升`、`50w+｜服务累计用户数`）

* [ ] 雷达图：维度名 3\~8 个 + 每维分值 1-10（如 `前端 8 / 后端 7 / 架构 6`）

* [ ] 技术标签：该阶段主要技术 5\~10 个

* [ ] 展开态补充要点 ≤5 条，每条一句话

## 5. 证书奖状（F8）

每张：`图片文件（jpg/png/webp，≤5MB）| 名称 | 获取时间 | 排序序号`

* [ ] 证书图片与信息

## 6. 站点配置（site\_config）

* [ ] GitHub 主页完整 URL

* [ ] 域名占位文案（未购域名阶段开机动画显示什么，默认 `localhost`）

* [ ] 其他外链（博客/掘金/Gitee 等，可选）

## 7. 彩蛋文案（F11）

* [ ] ASCII art 签名（可不提供，Agent 默认生成）

* [ ] 招聘联系方式一句

* [ ] 彩蛋秘籍与触发文案（默认 `↑↑↓↓←→←→BA`，可不提供）

## 8. 可选项

* [ ] 留言板欢迎语一句

* [ ] 开机动画伪日志 5 行（可不提供，Agent 用默认模板替换域名占位）
