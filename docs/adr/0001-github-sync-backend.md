# GitHub 数据由后端定时同步，前台永不直连 GitHub API

站主的 GitHub 仓库数据（作品）由后端定时任务（每日 03:00 + 后台手动触发）拉取 GitHub REST API 写入 MySQL，前台只读自己的库，访客浏览器不发起任何 GitHub 请求。换来的是：不受 GitHub 对未登录客户端 60 次/小时的限流、GitHub 故障时前台仍展示最近一次同步的缓存、可在同步数据上叠加中文描述/置顶/隐藏等运营字段。代价是数据非实时（最多滞后 24h）与一条同步链路需要维护。若未来需要更高实时性，调高同步频率即可，无需推翻此架构。鉴权使用站主个人访问令牌（只读公开仓库），经环境变量注入，不入库、不下发前端。
