# 上传文件内容改存数据库（upload_blob 表）

免费容器平台（Render 免费层等）每次休眠/重启/重新部署都会丢弃容器本地磁盘——简历 PDF 与证书图片若继续落盘会永久丢失。故把文件体统一存入 MySQL `upload_blob` 表（LONGBLOB），业务表只保留相对路径元数据；`/uploads/**` 从静态资源映射改为只读接口流式返回，URL 契约不变、前端无感。文件名含 UUID 且内容不可变，接口侧长缓存。

**Considered Options**：
- 挂持久卷——云平台持久卷收费且免费层不提供，被否。
- 对象存储（S3/R2 等）——需要额外账号与密钥管理，个人站用量（≤ 20MB/文件）用数据库更简单，被否。
- 保持落盘 + 部署时用付费实例——违背零成本目标，被否。
