# IP 归属地用 ip2region 离线库解析，地图打点按省聚合

访客 IP 的归属地解析选择内置离线库 ip2region（xdb 约 11MB，境内精确到城市级），不调用在线 IP API：无 QPS 限制、无外部服务可用性依赖、解析延迟近零。地图渲染按省级聚合打点（避免一线城市点位拥挤），hover 再展示该省城市 TOP 列表。代价是 xdb 文件需随版本更新（低频操作）。若日后需要境外 IP 高精度，再评估在线 API 作为补充而非替换。

**Considered Options**：在线 IP API（腾讯/淘宝等）——免维护但有限流、境外精度差、服务随时可能变更，被否。
