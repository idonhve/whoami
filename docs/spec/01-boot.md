# Spec 01 — F1 欢迎页：终端开机动画 + 首页 Hero + 全局前台布局

> 对应 PRD §F1、§5 页面结构 `/`、§4.1 性能红线。术语遵循 `CONTEXT.md`（开机动画、3D 锚点、降级模式）。
> 发布为 GitHub Issue #2（`idonhve/whoami`，标签 `ready-for-agent`）。依赖 Spec 00（地基）与 Spec 06 的 `GET /api/site-config`。

## Problem Statement

面试官打开网站的最初几秒决定去留。常规博客首屏信息密度低、加载白屏、缺乏记忆点，无法在 30 秒内让 HR/面试官看懂"这个人是谁、最强的是什么"。

## Solution

全站入口是一个终端"开机动画"欢迎页：逐行打印伪日志、光标闪烁、粒子过渡进入主页；随后首页 Hero 以姓名 + 一句话定位 + 打字机效果 + 3D 锚点 + 终端命令式入口命令呈现。整站视觉人格为程序员终端风（黑底 + 绿/青荧光 + 等宽字体），导航呈现为命令，页面切换像切窗口。同浏览器 24 小时内二次访问跳过开机动画。

## User Stories

1. 作为面试官，我希望打开网站先看到一个终端开机动画，以便立刻形成"这是个终端范儿工程师"的第一印象。
2. 作为面试官，我希望动画结束后的首页 Hero 在一屏内告诉我站主姓名、定位与最强技能，以便 30 秒内决定继续看。
3. 作为访客，我希望开机动画可点击跳过，以便赶时间时不被强制等待。
4. 作为访客，我希望二次访问不再重复开机动画，以便快速直达内容。
5. 作为访客，我希望动画全程有加载进度且无白屏，以便低端网络下体验不崩。
6. 作为移动端访客，我希望看到轻量版动画与静态渐变背景，以便流量与性能不受 3D 拖累。
7. 作为站主，我希望开机日志中的域名文案读取自站点配置，以便域名购买后改配置即可、不动代码。
8. 作为站主，我希望打字音效默认可静音且记住我的选择，以便不骚扰访客。
9. 作为技术同行，我希望导航命令与页面切换"切窗口"动效符合终端直觉，以便全站体验一致。
10. 作为站主，我希望后台能强制预览满血版（降级开关），以便上线前检查 3D 效果。
11. 作为访客，我希望从首页 Hero 的入口命令直达各核心区块，以便不依赖鼠标多级导航。
12. 作为站主，我希望首页预留"精选作品"与"简历下载"占位区块，以便后续模块（Spec 04/07）无冲突接入。

## Implementation Decisions

### 模块边界与依赖

- 前端模块目录：`src/views/boot/`（开机动画组件与伪日志文案常量）、`src/views/home/`（首页 Hero 与区块骨架）、`src/components/layout/`（AppHeader 命令式导航、AppFooter、页面切换过渡）。
- **本册建立公共文件（后续册在其上追加，不重建）**：`src/views/Home.vue`（Hero + "精选作品"占位 slot + "简历下载"占位 slot）、`AppHeader.vue`/`AppFooter.vue`（Spec 03 追加 GitHub 图标、Spec 10 追加 `>_` 图标）、`src/router/index.ts`（`/` 路由与守卫挂载点）。
- 依赖：Spec 00（脚手架、路由、通用约定）；Spec 06 的 `GET /api/site-config`（`domain`、`owner_name`、`degrade_force_full`）。无后端代码、无表、无新增 API。
- 24h 跳过标记：`localStorage` 键 `whoami:boot:seen`（存时间戳，过期 24h 自动失效）；静音偏好键 `whoami:boot:muted`。
- 降级判定：`navigator.hardwareConcurrency ≤ 4` 或视口宽 < 768px 时进入降级模式（静态渐变背景 + 轻量 CSS 动效）；`degrade_force_full=true` 时强制满血版。
- **本页 3D 锚点**：首页 Hero 的 Three.js 场景（本页唯一重动效锚点）；开机动画为过渡层，不计入锚点配额。
- 伪日志文案常量放模块目录内（≥ 5 行），域名部分从站点配置注入。

### API 契约

无新增接口。消费 Spec 06 定义的公开接口：

- `GET /api/site-config` → `data: { domain, ownerName, degradeForceFull, ... }`（仅公开白名单键）。

### 表结构

无本册表。消费 `site_config`（结构见 Spec 00 种子与 Spec 06 表结构）。

## 验收标准（逐条搬运自 PRD §F1）

* [ ] 打开网站先看到全屏终端动画：逐行敲出 `> initializing <域名> ...`、`> loading portfolio ...` 等至少 5 行伪日志，带光标闪烁与打字音效（可静音）

* [ ] 日志打印完成后粒子过渡动画进入主页，总时长 ≤ 2.5 秒，且支持点击跳过

* [ ] 动画期间显示加载进度，无白屏

* [ ] 二次访问（同浏览器 24h 内）跳过开机动画直接进主页（localStorage 标记）

* [ ] 桌面端与移动端均正常播放（移动端为轻量版动画）

* [ ] 开机日志中的域名文案读取自 `site_config` 配置；域名未购买时显示占位符（本地为 `localhost`），改配置不改代码

> 另需满足 PRD §4.1 红线（与验收相关者）：桌面端首屏 TTI ≤ 2s、全程无白屏；每页有且仅有一个 3D/重动效锚点；移动端/低配自动降级；3D 资源懒加载；首包 gzip ≤ 500KB（不含 3D 场景）。

## Testing Decisions

- 测试缝：组件行为 + 浏览器端到端（Playwright），不打 GSAP/Three.js 内部实现细节。
- 组件测试：伪日志行数 ≥ 5；跳过逻辑（mock `localStorage`：有有效标记 → 不播动画；标记过期 24h → 重播）；静音偏好持久化。
- Playwright 冒烟：首次访问播放动画且总时长 ≤ 2.5s、可点击跳过、无白屏（断言遮罩层常驻直至过渡完成）；二次访问直接进主页。
- 移动端模拟（375px 视口）走轻量动画路径；`hardwareConcurrency` mock ≤ 4 时降级渲染。
- Hero 文案来自站点配置的契约测试：改 `site_config.domain` 后开机日志文案随之变化。

## Out of Scope

- 首页"精选作品"区块内容渲染（Spec 04 填充占位）。
- 首页 Hero 简历下载按钮行为（Spec 07 填充占位）。
- 命令面板与 `>_` 图标（Spec 10）、GitHub 图标（Spec 03）、彩蛋（Spec 11）。
- 后端任何改动。

## Further Notes

- 首页 Hero 一句话定位与入口命令的文案素材来自 `docs/content/`（素材收集窗口 B 产出）；素材未到位前用占位文案开发，不阻塞验收。
- 主题色（绿/青荧光变体）与终端风字体等设计 token 在本册全局 CSS 变量中定义，供其余前端模块复用，避免各窗口配色漂移。
